# 发布文案模板（全模式必输出，单一来源）

任何主模式输出完图片/视频提示词后，末尾必须附一段可直接粘贴的抖音发布文案（图文帖文案区 / 视频发布文案区）。

公式：**钩子一句（萌点/痛点）+ 卖点一句（面料/版型/图案细节）+ 行动引导一句（挂车/尺码/评论区）**，一段成文，后接 3–5 个话题标签（固定含 #萌娃穿搭，按品类补 1–2 个）。

## 模式变体

- `trio-images` 图文向：文案与三张图互补——图1 已展示商品全貌，文案侧重穿着场景与细节卖点。
- `storyboard-images` / `beat-video` 视频向：可用「AI萌娃穿搭日记Day N | …」系列句式呼应账号人设；钩子句与视频 S1 钩子帧同向（剪映逐帧字幕模板见 storyboard-library.md §6，与发布文案分工不同）；阶段一先出文案初稿，阶段二随视频交付物复用并按成图微调。
- 用户显式给出文案方向或原文时原值锁定；未指定按公式编译并在参数锁定结果中标注「补充方向」。

## 编译与合规规则

- 卖点句必须从服装锁定块取材（品类/面料/颜色/贴布刺绣），不得虚构服装没有的卖点，不承诺功效。
- 不用「最」「第一」「国家级」等绝对化用语；不写品牌名与知名 IP 名（贴布用通用描述）；尺码等商品信息用占位提示用户按实际替换。
- 文案在发布阶段使用，图片/视频提示词内不出现任何文字。
- 发布时勾选「AI 生成」标识，不得描述为真实育儿记录。

## 示例

图文向（奶白蕾丝翻领上衣 + 水洗牛仔背心裙套装）：

```text
秋天就想给宝宝穿点软糯又精神的～米白蕾丝翻领小衫叠穿水洗牛仔背心裙，裙身上立体小兔头和小樱桃贴布，细节感拉满🐰丹宁软软的不板硬，宝宝跑跳不受限，幼儿园和周末遛娃都能穿，喜欢直接点购物车🧺（尺码按商品实际填）
#萌娃穿搭 #女宝宝穿搭 #人类幼崽穿搭大赏 #童装推荐 #秋冬穿搭
```

视频向（同套装）：

```text
AI萌娃穿搭日记Day 8 | 秋天给我家崽安排了这条牛仔背心裙，兔兔贴布太戳我了🐰内搭蕾丝领小衫软糯亲肤，丹宁不板硬跑跳不受限，幼儿园遛娃都能穿，同款挂车啦🧺（尺码按商品实际填）
#萌娃穿搭 #宝宝穿搭日记 #AI萌娃 #童装推荐 #秋冬穿搭
```
