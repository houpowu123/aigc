# 海报四联换装模板（poster-swap，路径 C 换装编辑，2026-09-17 定稿接入）

抖音「人类幼崽杂志风」四联海报：四种固定版式（样式1–4）各一张，全部用**路径 C 换装编辑**生成——参考海报作底图，只换衣服。

## 0. 触发与工作流

- **触发**：用户上传一张服装图，并提及「海报 / 四联海报 / 海报四件套 / 换装」等，或按本工作流直接说「出四条海报提示词」。
- **工作流**：用户上传服装图 → 编译服装锁定块（image-roles-and-locks.md §3，先与服装图逐项核对）→ 输出**四条换装提示词**（样式1–4 各一条）+ 一段图文向发布文案（caption-template.md）→ 用户在即梦**编辑/多图参考模式**下逐条配对出图：**图1 = 对应底图海报（参考权重/主体一致性拉最高）、图2 = 服装图**。
- **四张底图海报为固定资产**，存放本 skill 目录 `assets\poster-bases\`：`样式1-捧脸小窗.jpg`、`样式2-展臂贴墙.jpg`、`样式3-坐姿圆镜.jpg`、`样式4-提袋展示.jpg`。
- 本模式**无身份锁定块、无月龄门控**：底图自带人物，服装锁定块是唯一变量；也不需要画幅参数（底图决定）。
- 样式族共同结构：**主画面 + 第二画面**（样式1=胶囊小窗、样式2=无、样式3=圆镜反射、样式4=袋面印刷图）；第二画面的「同步换装」条款是成败关键。

## 1. 通用编译规则（四条提示词共用）

- 开头句逐字：`以参考图一的海报为基础进行换装编辑，生成一张 9:16 竖版海报。`
- 服装槽位逐字：`将宝宝身上所穿的服装更换为参考图二中的同款童装套装：{新服装锁定块}`——槽位只填服装细节描述（以「外搭…内搭…」开头，含颜色无色差句，不含「宝宝穿着」主语）。
- 服装图绑定句逐字：`忽略参考图二中被双手提着的姿态与背景，服装与参考图二完全同一件、细节一致无色差`。
- 水印条款每条必有：`同时移除画面底部的水印文字行。`
- 收尾声明逐字：`除上述服装更换与水印移除外，画面其余一切与参考图一保持一致。`
- 负面尾注 = 通用核心（下）+ 样式专属条款（见各样式卡）。

通用负面核心：

```text
避免：宝宝脸部或发型变化、表情改变、姿势或头部角度改变、背景墙面造型改变、光影氛围改变、文字被改动消失或拼写变化、新增任何元素、服装与参考图二不一致、贴布刺绣数量位置错误、纽扣丢失或变色、品类版型改变、面料质感误读、塑料感、CG感、多余文字、水印、多宫格拼图。
```

## 3. 标准输出（本模式）

1. 参数锁定结果：服装图路径 + 编译出的服装锁定块原文（低分辨率服装图须标注「按可见特征编写、出图后与实物核对」）。
2. 四条提示词：样式1–4 各一个 `text` 代码块，每块标注配对的底图文件名。
3. 图文向发布文案一段（caption-template.md）。
4. 通道说明：即梦编辑模式、图1=底图（权重最高）、图2=服装图、四张底图在本 skill 目录 `assets\poster-bases\`。

## 4. 审计

- 四条提示词齐全且各配对正确底图？
- 服装锁定块四条逐字一致（同一套衣服）？
- 样式1/3/4 的第二画面同步换装条款在位？样式2 确认无第二画面条款？
- 水印移除条款每条都有？
- 通用负面核心在位且样式专属条款齐全？
- 服装锁定块先与服装图逐项核对（含低分辨率预期管理）？
