# 三图图文模板（手提展示 + 上身展示 ×2）

抖音图文帖形态（「人类幼崽穿搭大赏」式）：图1 用人手提起衣服展示商品全貌，图2/图3 宝宝上身效果。输入与主流程一致（宝宝形象图 + 服装图），画幅默认 **3:4 竖版**（抖音图文规格，用户锁定值优先）。

## 0. 组成与参考图

| 图 | 内容 | 参考图 | 出现宝宝 |
|---|---|---|---|
| 图1 | 人手提着衣服的展示图 | 仅 GARMENT（裁掉品牌标） | 否（仅一只成年女性的手） |
| 图2 | 宝宝上身展示 | IDENTITY + GARMENT 双参考 | 是 |
| 图3 | 宝宝上身展示 | IDENTITY + GARMENT 双参考 | 是 |

三图共用同一服装锁定块（逐字）；图2/图3 共用身份锁定块与光线句。图1 不使用身份锁定块。

## 1. 图1 手提展示图规则

- **构图（实测校准：抖音母婴图文标准姿势）**：双手从画面**上方两个上角**伸入（手臂沿上边缘进入，不得从左右两侧水平伸入），指尖分别轻捏服装**肩线/领口两侧**，将服装**自然提起悬挂**——衣服受重力自然下垂、保留真实悬垂褶皱，不是水平摊开展示；仅双手与少量手腕入画，无手臂、无面部、无其他人物。
- **提握点对照**：背带裤/连体衣 → 指尖捏左右肩线上端；连衣裙/套装 → 指尖捏肩线或领口两侧；也可捏衣架提梁两端。
- **服装状态**：受重力自然垂坠、保留真实悬垂褶皱，正面关键细节朝前完整可见、不被指尖遮挡，肩到下摆全部入画。
- **背景（生活感优先）**：默认生活化室内一角（如深色木门＋白纱帘、墙面与地板交界），室内自然光；用户指定纯色棚拍背景时才用奶油白/浅灰。生活化背景更真实、更去 AI 感。
- **编译顺序**：画幅句 → 任务句（双手提展示）→ **商品绑定句**（服装必须与参考图二中的同一件完全一模一样，一切细节以参考图为准——实测教训：缺少此句时模型只按文字自由发挥，成图与上传服装不一致）→ 服装锁定块（逐字，且锁定块内容必须先与参考图逐项核对）→ 双手与提握描述 → 背景与光线质感 → 负面尾注（追加手部条款与一致性条款）。

## 2. 图2/图3 上身展示图规则

按 prompt-templates.md 的帧结构（①–⑨）编译，差异指纹天然区分（全身 + 特写）：

- **默认**：图2 = P1 正面全身站姿（主展帧指纹）；图3 = P14 坐姿低头看胸前口袋（卖点帧指纹，俯角特写）。
- 可换：P2 扶床头、P3 背身回眸、P7 拍手笑等；用户显式指定姿势/背景时原值锁定。
- 背景：与房间基调一致（用户值优先）；两图景别不同（全身 + 特写），天然满足差异审计。

## 4. 回检

- 图1：**两只手分别**数手指（各五指正常、左右对称）、确认无人物面部、服装关键细节与参考图逐项一致。
- 图2/图3：按 prompt-templates.md 第 6 节成图回检清单执行。
- 三图画幅一致（用户锁定值）。

## 5. 发布文案（图文带货，trio 模式必输出）

三条提示词之后附一段可直接粘贴的抖音图文发布文案。公式、图文向变体、合规细则与示例统一见 [caption-template.md](caption-template.md)（单一来源）；文案在发布阶段填写，图片提示词内不出现任何文字。
