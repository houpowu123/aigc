# 生成通道与能力边界

## 1. 全链路管线（抖音萌娃带货）

```text
①IP 根资产（一次性）     AI 宝宝形象：GLM-Image 文生图（已验证，0.1元/张）或豆包/即梦生成，选定后锁定
②分镜出图（每套服装）    即梦/Seedream 4.0 多图参考：宝宝图(IDENTITY) + 服装图(GARMENT) + 帧提示词，逐帧生成
③视频（每条）            即梦 Seedance 多图生视频（提示词见 video-script-template.md）或剪映轮播剪辑
④发布                    抖音：勾选 AI 生成声明，挂小黄车，AI萌娃不伪装真实育儿
```

## 2. 通道事实清单

| 通道 | 参考图输入 | 用途 | 备注 |
|---|---|---|---|
| GLM-Image（open.bigmodel.cn） | ❌ 仅文生图 | 仅用于①根资产生成（虚构宝宝，0.1 元/张） | 本机已验证；不能做服装上身还原 |
| 即梦 / Seedream 4.0（网页版） | ✅ 多图参考 | ②分镜出图主通道：宝宝图+服装图双参考 | 抖音生态，国内可用 |
| 火山引擎 Seedream / Seedance API | ✅（以官方文档为准） | ②③自动化批量 | 接入前先核实多图参考参数与计费 |
| 即梦 / Seedance 多图生视频 | ✅ 多张首帧图 | ③自动生成卡点轮播视频 | 与 video-script-template.md 配套 |
| 剪映（手动） | 成图 | ③轮播剪辑最稳路径：自动踩点+字幕+卡点 | 不依赖 AI 视频生成质量 |
| Nano Banana / GPT-4o 图像 | ✅ 多图合成 | ②备选 | 网络与合规自行评估 |

各平台接口参数随版本变化，接入新通道前以官方文档核实「多图参考」能力，不要凭记忆假设。

## 3. direct-generate 前置检查

1. IP 根资产未锁定时，先完成①（GLM-Image 生成候选让用户选定）。
2. 确认可用通道及参考图能力（可 Bash 调 API 测试）。
3. 分镜出图必须支持 IDENTITY + GARMENT 双参考，否则如实说明并回退 prompt-only（GLM-Image 不具备该能力，不得硬凑）。
4. 视频任务需要分镜成图已存在；无视频通道时回退 prompt-only 并给出即梦/剪映操作指引。

## 4. prompt-only 回退输出格式（默认）

1. 每帧一条完整分镜提示词（含双锁定块、姿势句、背景句与负面尾注）。
2. 出图指引：`即梦图片生成 → 多图参考：第1张=宝宝形象图（人物参考），第2张=服装商品图（产品参考）→ 粘贴该帧提示词 → 画幅 9:16`，逐帧重复。
3. 视频指引：按 video-script-template.md 选择交付物 A（即梦多图生视频）或 B（剪映脚本）。
4. 提醒：宝宝参考图先裁掉水印；AI 内容发布时勾选平台 AI 声明。
