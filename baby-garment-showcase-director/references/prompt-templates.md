# 图片提示词编译规则（分镜帧）

每张分镜图 = 同一个宝宝 + 同一套衣服 + 该帧的叙事职责。提示词的骨架是「不变的东西逐字重复，变的东西按帧替换」。

## 1. 帧提示词编译结构（G 组通用，按顺序）

```text
①画幅句        生成一张 9:16 竖版（或用户锁定画幅）、真实摄影质感的萌娃穿搭分镜图。
②身份锁定块    （image-roles-and-locks.md，逐字复用，每帧相同）
③服装锁定块    （image-roles-and-locks.md，逐字复用，每帧相同）
④分镜帧描述    本帧差异指纹句（景别+机位角度+机位高度+动态程度，按分镜表逐帧取用）+ 姿势句（姿势库逐字）+ 道具句（如有）
⑤背景句        （背景库逐字；同场景帧共用同一句）
⑥光线句        柔和均匀漫射光从正上方覆盖，无强阴影，服装颜色真实准确、无色差，面料纹理清晰。
⑦质感句        高清写实细节，婴儿皮肤保留自然绒毛与真实质感，生活真实感，不过度影楼精修。
⑧独立声明      单张独立照片，不是拼图、组图、分镜或多宫格。
⑨负面尾注      （见第 3 节）
```

禁止把帧序号、叙事职责名称（如「钩子帧」）、分镜表、参数锁定等解析性文字写进提示词——提示词里只有画面。

## 2. 连贯性编译规则

1. ②③块在全部帧中**逐字相同**——这是「同一宝宝、同一件衣服」的唯一保障，严禁改写或缩写。
2. ⑤背景句按分镜表的「拍摄角落」取用（同一房间 2–3 个角落变体，句可不同），但光线句⑥保持全组一致。
3. ④中的姿势句从姿势库逐字取用；差异指纹句按 storyboard-library.md 分镜表逐帧书写（景别、机位角度、机位高度、动态程度），**相邻帧至少 3 个维度不同且机位角度必须不同；正面全身标准展示帧全组唯一**。
4. 生活真实感优先：默认不写「影楼精修」「高级感」；用户明确要求精修风时替换⑦质感句并标注。
5. 每帧独立生成（用户在即梦逐帧出图），提示词不引用其他帧（不写「与上一张同场景」）。

## 3. 负面尾注（每帧末尾逐字附加）

```text
避免：服装变形变色、颜色偏差、品类改变、版型改变、装饰丢失或新增、结构错乱、面料质感误读、过曝导致浅色面料细节丢失、塑料感、CG感、强影楼感、无关文字、Logo、水印、多宫格拼图；换脸、成人化五官、身体比例异常、多手多指、肢体融合、月龄不符动作、道具遮挡口鼻、背景杂乱、人物遮挡服装主体。
```

## 5. 审计要点

- 逐帧核对：①–⑨九个成分齐全？②③与其他帧逐字一致？姿势月龄门控通过？
- **差异审计**：逐帧核对差异指纹——相邻帧 ≥3 个维度不同且机位角度不同？全身帧 ≤3 张且角度互异？正面全身帧唯一？两帧并排读不雷同？
- 角落背景句与房间基调一致，光线句全组相同？

## 6. 成图回检（用户出图后的 QC 清单）

多帧生成是独立抽卡，模型会随机漂移细节。用户回传成图后按此清单逐帧核对，不合格帧重抽：

1. **文字刺绣逐字一致**（最高频漂移点）：同款服装的刺绣文字在每帧必须逐字相同（如 `Cute cherry`），出现 `Cherry&cherry` 等变体即判不合格；重抽时在提示词中把文字逐字写入：`袋面刺绣文字为"Cute cherry"，字样清晰无拼写变化`。
2. 装饰扣数量与位置、背带颜色、碎花密度、裤脚卷边每帧一致。
3. 宝宝发际线、脸型与根资产一致，无换脸漂移。
4. 光线色调全组统一；逆光帧不超过 1 张（且应出现在背面帧，叙事上合理）。
5. 相邻帧无「同道具+同姿态+同机位」的近似重复；出现时替换其中一帧的姿势或角落。
