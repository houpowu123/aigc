# 拼贴首帧模板（七宫格 · 白边贴纸风）

一张拼贴海报 = 中央正面照 + 左右各三张贴纸（s1–s6 六个造型）。它是整条内容的「封面 + 视频种子」：后续的卡点视频以此图为首帧，按节拍依次「进入」每个贴纸的造型。

## 1. 版式规格（9:16 竖版）

```text
┌───────────────────┐
│ ┌───┐        ┌───┐ │
│ │s1 │        │s4 │ │
│ └───┘        └───┘ │
│ ┌───┐ ┌────┐ ┌───┐ │
│ │s2 │ │宝宝│ │s5 │ │
│ └───┘ │正面│ └───┘ │
│ ┌───┐ └────┘ ┌───┐ │
│ │s3 │        │s6 │ │
│ └───┘        └───┘ │
└───────────────────┘
```

- 中央大图：宝宝**上半身正面微笑近景**（脸部与领口服装细节清晰），占画面约六成宽，人物居中。**中央造型必须与六张贴纸全部不同**——否则换装视频中该贴纸飞入时模型会跳过动画直接沿用中央画面（实测教训）。
- 左列自上而下 = 分镜 S1、S2、S3；右列自上而下 = S4、S5、S6（与视频切换顺序一致）。
- 贴纸之间、贴纸与中央图之间留白均匀，不重叠、不出血。

## 2. 贴纸风格

白边贴纸风：白色粗描边、轻微下方投影、每张各自轻微倾斜角度（3–8 度不等），内部为真实摄影质感照片。

## 3. 提示词编译顺序

```text
①画幅与任务句   9:16 竖版萌娃穿搭拼贴海报，由一个中央大图与六张白边贴纸组成
②整体一致性句   所有画面中为同一个宝宝、同一套服装，身份与服装细节完全一致
③身份锁定块     （image-roles-and-locks.md，逐字）
④服装锁定块     （image-roles-and-locks.md，逐字 + 刺绣文字逐字锁定，如"Cute cherry"）
⑤中央大图描述   正面全身站立 + 场景（与主展帧 S3 同风格）
⑥贴纸风格句     白色粗描边、轻微投影、各自轻微倾斜
⑦贴纸内容 1–6   按分镜表 S1–S6 的姿势/景别逐条压缩描述（每条 1–2 句）
⑧海报底色句     奶油白暖调纯色或柔纹理背景，留白均匀，无其他元素
⑨质感与文字声明 高清写实；海报上除服装刺绣外不出现任何文字、水印
⑩负面尾注       （见第 5 节）
```

生成方式：即梦图片生成，双参考（图一=人物参考、图二=产品参考）+ 本提示词；**不需要上传 s1–s6 成图**——六个贴纸由提示词直接描述、AI 直接画出。

## 4. 一致性要点

- 贴纸内容必须与分镜表 S1–S6 的姿势/景别/道具一一对应（视频要靠这些贴纸驱动）。
- 刺绣文字在中央图与六张贴纸中共出现 7 次，必须逐字一致——这是拼贴图最高频的漂移点。
- 身份块只描述一次（②③），靠「所有画面中一致」约束七个画面，不逐张贴纸重复身份块。

## 5. 负面尾注

```text
避免：贴纸数量不是六张、贴纸与中央图重叠或被裁切、各画面中宝宝或服装不一致、刺绣文字变化或拼写错误、装饰扣数量位置变化、某张贴纸出现其他服装、成人化、动漫化、多手多指、肢体融合、无关文字、Logo、水印、画面杂乱。
```

## 6. 成图回检

按 prompt-templates.md 第 6 节执行，重点：①数贴纸（必须 6 张且内容顺序对应）；②逐张贴纸核对刺绣文字逐字一致；③每张贴纸里的宝宝是同一张脸。不合格整张重抽（拼贴图无法单贴修补，建议抽 3–4 次选最优）。

## 7. 方式 B：基于六张成图的 AI 合成版（用户已生成 s1–s6 时优先）

与第 3–5 节的「纯提示词直出」并列的另一条路线：把 s1–s6 六张成图上传给即梦图片编辑/多图参考，让 AI 只做排版合成。**优势：贴纸就是真实成图，服装细节零漂移；关键约束：提示词必须禁止重绘。**

合成提示词模板：

```text
将上传的 @Image 1 至 @Image 6 合成为一张 9:16 竖版的萌娃穿搭拼贴海报，只做排版合成，禁止重绘或修改任何图片内容：六张图中为同一个{月龄}宝宝、同一套{服装简述}，合成后每个画面中的宝宝脸型、服装颜色、版型、刺绣文字"{刺绣文字逐字}"与装饰扣必须与原图完全一致，不得改变姿势、景别或背景。
素材映射：@Image 1＝{S1 造型简述}；@Image 2＝{S2 造型简述}；@Image 3＝{S3 造型简述，若为正面全身则兼任中央图}；@Image 4＝{S4 造型简述}；@Image 5＝{S5 造型简述}；@Image 6＝{S6 造型简述}。
版式：@Image {中央帧号} 作为中央竖版大图放大呈现，占画面约六成宽，人物完整居中；其余各图做成白边贴纸环绕——左列自上而下为{…}，右列自上而下为{…}，贴纸之间及与中央大图之间留白均匀，不重叠、不被裁切。
贴纸风格：白色粗描边、轻微下方投影、各自轻微倾斜角度（3–8 度不等），内部画面保持原图不变；中央大图无描边。
整张海报底色为奶油白色暖调柔纹理背景，温馨干净；除服装刺绣文字"{刺绣文字逐字}"外，海报上不出现任何其他文字、Logo 或水印。
避免：贴纸内画面被重绘、宝宝或服装与原图不一致、刺绣文字变化、贴纸数量错误、贴纸与中央图重叠、边缘裁切、画面变形、无关文字、水印。
```

- 若用户要求严格「中央 + 六张贴纸」共 7 格：中央用正面帧，六张贴纸含全部六图（正面帧会出现两次，属用户指定，照做并注明）。
- 回检同第 6 节，另加：每张贴纸内容与对应原图逐帧一致（合成模型可能偷换姿势）。
- 两条路线的选择：已生成 s1–s6 → 方式 B（细节零漂移）；尚未生成分镜图或只要封面 → 方式 A（直出，有重绘漂移风险）。

## 8. 方式 B 的保真边界与手动拼贴（要求贴图与原帧完全一致时）

**AI 合成的固有限制**：合成模型按原图「照着画」，无法逐像素复制。提示词写再多「禁止重绘」也只能降低漂移概率，不能保证。用户要求「每个贴图与每帧图片完全一样」时，必须明示以下取舍：

- **手动拼贴（唯一 100% 保证）**：约 10 分钟——
  1. 美图秀秀/剪映对 s1、s2、s4、s5、s6 分别「智能抠图」（s3 作中央图不抠）；
  2. 每张抠图加白色描边（美图秀秀「描边」功能，粗细约 8–12）；
  3. 新建 9:16 画布，底色奶油白（#FAF6F0 类暖调）；
  4. 中央放 s3 原图（约占六成宽），左右贴入贴纸并各自旋转 3–8 度；
  5. 导出 PNG。服装、刺绣、表情逐像素与原帧一致，零漂移。
- **AI 合成（快但概率性）**：用第 7 节强化提示词，出图后逐贴回检，不合格重抽；接受「贴纸与原图有轻微差异」的前提。
- 用户明确说「必须完全一样」→ 默认给手动流程，AI 合成版仅作为快糙备选附上。
