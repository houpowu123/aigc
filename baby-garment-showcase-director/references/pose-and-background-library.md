# 姿势库与背景库（分镜帧组件）

## 0. 优先级规则（与 female-portrait-director 的参数锁定逻辑一致）

1. **用户显式填写姿势或背景 → 原值锁定**，逐字写入对应帧提示词；与月龄安全冲突时提示一句并给同组安全替代，不得静默替换。
2. **未填写 → 按 storyboard-library.md 分镜表的默认列取值**，并在输出参数锁定结果中标注「补充方向」。
3. **背景**：用户指定的背景编号 = **房间基调**（如 B4 = 该房间的窗边光环境）。允许并鼓励在同一房间内派生 2–3 个拍摄角落（窗台边 / 地毯 / 床沿）制造帧间差异：角落变体的背景句可按角落改写，但色调与光线句必须全组一致。场景连续性看「同一个家」，不看「同一面墙」。
4. 姿势句与背景句逐字写入每帧图片提示词；视频阶段不再改写（视频里宝宝状态 = 各帧照片状态）。
5. 用户可扩充本库：新增姿势接 P13、P14…，新增背景接 B8、B9…，格式与本文件一致即可。
