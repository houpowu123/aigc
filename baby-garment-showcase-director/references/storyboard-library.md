# 分镜叙事库（单套精讲）

一条视频 = 一个小故事 = 一套衣服。分镜的本质是「按生活逻辑推进的一组抓拍」。**连贯靠宝宝与服装锁定，好看靠帧与帧的差异**——本库同时锁定这两件事。

## 1. 叙事三段式（抖音带货结构）

```text
钩子（前 3 秒）：最萌状态 + 衣服最清楚的一帧，决定用户是否划走
卖点（中段）：玩耍动态 → 全貌展示 → 版型背面 → 细节特写，层层递进
收尾（最后 2–3 秒）：好感特写 + 挂车引导留白
```

## 2. 帧间差异系统（防「六张图长一样」的核心机制）

### 2.1 六个差异维度

| 维度 | 取值范围 |
|---|---|
| D1 景别 | 面部特写 / 上半身近景 / 中近景 / 全身 |
| D2 机位角度 | 正面 / 45° 侧 / 正侧面 90° / 背面 3/4 / 俯角 / 低机位仰角 |
| D3 动态程度 | 静态摆拍 / 微动态（低头、转头）/ 强动态瞬间（爬行、迈步、拍手中） |
| D4 道具互动 | 无 / 玩偶 / 玩具 / 扶物 / 窗帘床品 |
| D5 视线 | 看镜头 / 看道具 / 看窗外 / 回眸 / 低头看自己 |
| D6 机位高度与景深 | 平视 / 俯角 / 仰角；浅景深 / 深景深；有前景元素（虚化窗纱、玩具） |

### 2.2 差异硬规则

1. **相邻两帧至少在 3 个维度上不同，其中 D2 机位角度必须不同。**
2. **全身帧全组最多 3 张**，且机位角度必须互异（正面 / 侧面 / 背面各一）。
3. **正面全身标准展示帧全组唯一**（只给主展帧）——这是出现「两张图长得一样」的最常见原因。
4. 特写帧（卖点、收尾）必须用不同机位高度（一俯一仰）或不同视线方向区分。
5. 每帧在提示词中写入「差异指纹句」（景别+角度+机位高度+动态程度），编译时按分镜表逐帧取用。

## 5. 叙事连贯性硬规则

1. **背景参数 = 房间基调，不是同一面墙**：用户指定某背景编号（如 B4）时，表示整个故事发生在该光环境的同一房间里；允许并**鼓励**在房间内使用 2–3 个拍摄角落（窗台边 / 地毯 / 床沿），角落的背景句可以不同，但色调与光线句必须全组一致。场景连续性看「同一个家」，不看「同一面墙」。
2. **动作链衔接**：帧与帧之间的宝宝状态要能连成一段真实时间（盘坐玩耍→扶走→站立展示→转身），不出现断裂。
3. **服装跨帧零漂移**：每帧逐字复用服装锁定块；姿势变，衣服绝不变。
4. **宝宝跨帧零漂移**：每帧逐字复用身份锁定块（IP 根资产）。
5. **第一帧即钩子**：表情最萌 + 服装清楚可见。
6. 用户自定义分镜：锁定用户的帧序与职责，仍自动套用帧间差异系统。

## 6. 文案模板（剪映阶段使用，不进图片提示词）

- 钩子字幕（前 3 秒，选一）：`12 个月的宝宝秋冬这么穿，回头率拉满` / `这件背带裤也太太太可爱了8` / `谁懂啊，宝宝穿上就不肯脱`
- 卖点字幕（中段，每帧一句）：`灯芯绒面料，厚实不起球` / `樱桃刺绣，细节绝了` / `翻边裤脚，能穿两季`
- 结尾引导（最后 2 秒）：`同款在小黄车👇` / `给宝宝冲一件～`
- 发布文案模板：`AI萌娃穿搭日记Day N | 今天这套XX也太乖了，同款挂车啦 #萌娃穿搭 #童装 #宝宝穿搭日记 #AI萌娃`
- 标签：3–5 个，固定带 #萌娃穿搭，按品类补 1–2 个。
- 发布文案（任务输出末尾随图片提示词一并交付，不是只有视频阶段才有）：统一按 [caption-template.md](caption-template.md) 的视频向变体编译；上方字幕模板用于剪映阶段逐帧字幕，两者分工不同。
